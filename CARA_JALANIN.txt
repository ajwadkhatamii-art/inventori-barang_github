CARA MENJALANKAN
1. Install XAMPP, nyalakan Apache dan MySQL.
2. Copy folder "inventori" ke C:\xampp\htdocs\
3. Buka http://localhost/phpmyadmin -> tab Import -> pilih database.sql -> Go.
4. Buka http://localhost/inventori
